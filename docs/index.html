Install (Chrome/Edge)

  1. Unzip the downloaded file.
  2. Open chrome://extensions (Edge: edge://extensions).
  3. Enable Developer mode.
  4. Click Load unpacked and select the unzipped folder (must contain manifest.json).
  5. Open a LeetCode problem page to use the extension.

Troubleshooting

  • If UI doesn’t appear, refresh the LeetCode page.
  • If you previously loaded another version, click Reload in the Extensions page.
  • For updates, repeat download and Load unpacked.
